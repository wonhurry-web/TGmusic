## 3. ADB 真机部署调试

### 3.1 手机准备

1. 打开「设置 → 关于手机」，连续点击「版本号」7 次启用开发者选项。
2. 进入「开发者选项」，开启「USB 调试」。
3. 用 USB 数据线连接电脑，手机弹窗点「允许」。

### 3.2 确认连接

```bash
adb devices
```

输出中出现设备序列号且状态为 `device` 即表示连接成功：

```
List of devices attached
XXXXXXXXXXXX    device
```

### 3.3 常用 ADB 命令

```bash
# 查看已连接设备
adb devices

# 安装 APK（-r 覆盖安装）
adb install -r app-debug.apk

# 卸载
adb uninstall com.syncwave.app

# 启动应用
adb shell am start -n com.syncwave.app/.MainActivity

# 查看实时日志（调试关键）
adb logcat

# 过滤本项目日志
adb logcat | grep SyncWave

# 截图
adb shell screencap -p /sdcard/screen.png && adb pull /sdcard/screen.png

# 端口转发（Web 开发服务器 → 手机）
adb reverse tcp:5173 tcp:5173
```

### 3.4 快速调试流程（Vite + 手机浏览器）

无需打包 APK，即可在手机上实时预览开发页面：

```bash
# 1. 电脑启动开发服务器
npm run dev

# 2. 端口转发（手机访问 localhost:5173 即访问电脑）
adb reverse tcp:5173 tcp:5173

# 3. 手机浏览器打开
# http://localhost:5173
```

> 此方式修改代码后手机端热更新，适合框架阶段快速调试。

## 4. Capacitor 打包 Android

### 4.1 首次配置

```bash
# 安装 Capacitor（如未安装）
npm install @capacitor/core @capacitor/cli @capacitor/android

# 初始化配置（如无 capacitor.config.ts）
npx cap init

# 添加 Android 平台（仅首次）
npx cap add android
```

### 4.2 配置 Android SDK

1. 安装 Android Studio，通过 SDK Manager 安装 Android SDK Platform 34+ 与 Build Tools。
2. 设置环境变量：

```bash
# Windows（PowerShell，永久）
[Environment]::SetEnvironmentVariable("ANDROID_HOME", "C:\Users\Administrator\AppData\Local\Android\Sdk", "User")
```

3. 验证：

```bash
echo $ANDROID_HOME
```

### 4.3 构建与安装

```bash
# 构建 Web 产物
npm run build

# 同步到 Android 项目
npx cap sync

# 用 Android Studio 打开（推荐，可直接运行到手机）
npx cap open android

# 或命令行构建 APK
cd android && ./gradlew assembleDebug
```

APK 输出路径：

```
android/app/build/outputs/apk/debug/app-debug.apk
```

### 4.4 ADB 安装

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## 5.5 真机 APK 构建（本机实测通过）

本机已把构建工具链放在项目 `tools/` 目录（不污染系统环境），并实测编译安装成功。

```bash
# 1) 前端构建 + 同步到 Android
npm run build && npx cap sync android

# 2) 设置 JDK 21（Capacitor 7 的源码级别为 21）并编译
export JAVA_HOME="D:/ai项目在这/音乐app/tools/jdk21/jdk-21.0.13+9"
export PATH="$JAVA_HOME/bin:$PATH"
D:/ai项目在这/音乐app/tools/gradle-8.11.1/bin/gradle.bat -p android assembleDebug --no-daemon

# 3) 安装（ColorOS 等定制系统会阻塞普通 adb install，root 设备用 su 静默安装）
adb push android/app/build/outputs/apk/debug/app-debug.apk /data/local/tmp/syncwave.apk
adb shell "su -c 'pm install -r -t /data/local/tmp/syncwave.apk'"
adb shell monkey -p com.syncwave.app -c android.intent.category.LAUNCHER 1
```

**本机工具链版本**（均在项目 `tools/` 与 `D:/AndroidStudio/SDK`）：
- JDK：Temurin 21.0.13（Gradle 8.11 + Capacitor 7 需源码级别 21）
- Gradle：8.11.1（从阿里云镜像下载，绕过 GitHub 代理限制）
- Android SDK：`D:/AndroidStudio/SDK`（platform android-35 + build-tools 35.0.0 已补齐）
- 关键配置：`android/gradle.properties` 加了 `android.overridePathCheck=true`（项目路径含中文）、`local.properties` 指向 SDK；Manifest 开启明文流量。

**真机连服务端**：App 默认服务器地址 `ws://192.168.1.101:6666`（本机局域网 IP）。
更换网络后，到设置中心 → 一起听同步 → 服务器配置，改成电脑当前局域网 IP 即可；
音乐代理地址由 App 自动从该地址推导（`ws://` → `http://`）。服务端需监听 `0.0.0.0`（默认已是）。

## 6. 常见问题

| 问题 | 解决 |
| --- | --- |
| `adb devices` 无设备 | 检查 USB 调试、数据线、驱动；重试 `adb kill-server && adb start-server` |
| `adb` 提示 unauthorized | 手机弹窗点「允许 USB 调试」 |
| Gradle 报 `Unsupported class file major version` | JDK 版本不匹配：Java 25 过高（Groovy 不支持），Java 17 过低（源码级别 21）；用 JDK 21 |
| Gradle 报路径含非 ASCII | `android/gradle.properties` 加 `android.overridePathCheck=true` |
| Gradle 报依赖需 compileSdk 33+ | 补齐 SDK platform android-35 与 build-tools 35.0.0 |
| `adb install` 卡在 Performing Streamed Install | 定制系统（ColorOS 等）阻塞确认框；root 设备用 `adb shell "su -c 'pm install -r -t <apk路径>'"` |
| 截图全黑 | 设备屏幕熄灭；先 `adb shell input keyevent 224` 唤醒并 `wm dismiss-keyguard` |
| 端口转发失效 | 重新执行 `adb reverse tcp:5173 tcp:5173` |
| Capacitor 白屏 | 确认 `npm run build` 已执行、`webDir` 指向 `dist` |
| 真机搜索无结果 | 服务端 `mobilecdn.kugou.com` 可达性；不通时 App 自动降级内置曲库 |
