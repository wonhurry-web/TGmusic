| 项 | 内容 |

---

## 1. 设计原则

1. **精简**：单主页面，去除多余层级，一屏内完成主要操作。
2. **美观**：统一的视觉语言，克制的动效，讲究留白与节奏。
3. **一致**：组件、间距、圆角、色彩遵循统一规范。
4. **可达**：触控目标 ≥ 44px，重要信息对比度充足。
5. **愉悦**：细微动效与微交互提升质感，但不喧宾夺主。

---

## 2. Logo 规范

- **构成**：黑色方形底 + 居中银色音符。
- **底色**：纯黑 `#000000`（规范色值），实际渲染用近黑 `#0A0A0A` 增强层次。
- **音符**：银色渐变（`#F5F7FA → #B8C0CC → #8A94A3`），带高光与轻微阴影，营造金属质感。
- **形状**：八分音符（单个符头 + 符干 + 符尾），圆润现代。
- **比例**：音符占画布约 50%，居中。
- **格式**：SVG（矢量，主用）+ PNG（导出备用，192/512/1024）。
- **文件**：`public/logo.svg`。

> 设计意图：黑色代表沉稳与沉浸，银色音符代表音乐的纯粹与质感，呼应「精而强」的定位。

## 3. 配色系统

### 3.1 黑白主题 — 浅色（默认 light）

| 语义变量 | 色值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#F7F8FA` | 页面背景 |
| `--color-surface` | `#FFFFFF` | 卡片/面板 |
| `--color-text` | `#1A1D24` | 主文字 |
| `--color-text-sub` | `#7A8290` | 次级文字 |
| `--color-primary` | `#2C2F38` | 主强调（近黑） |
| `--color-accent` | `#C0A062` | 点缀（银金） |
| `--color-border` | `#E6E8EC` | 分隔线 |

### 3.2 黑白主题 — 深色（dark）

| 语义变量 | 色值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#0A0A0A` | 页面背景 |
| `--color-surface` | `#15161A` | 卡片/面板 |
| `--color-text` | `#F2F3F5` | 主文字 |
| `--color-text-sub` | `#8A8F9A` | 次级文字 |
| `--color-primary` | `#E8EAED` | 主强调（银白） |
| `--color-accent` | `#D4B072` | 点缀 |
| `--color-border` | `#26282E` | 分隔线 |

### 3.3 炫彩主题（colorful）

- 背景：深色底 + 流动渐变光晕（紫 `#7B5CFF`、青 `#22D3EE`、粉 `#F472B6`）。
- 强调色：随主色循环渐变。
- 卡片：半透明玻璃拟态（`backdrop-filter: blur`）。
- 动效：缓慢流动的背景光斑，克制不刺眼。

## 4. 字体与排版

| 项 | 规范 |
| --- | --- |
| 字体族 | 系统字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` |
| 标题 | 18–20px / 600 |
| 正文 | 14–16px / 400 |
| 辅助 | 12px / 400 |
| 行高 | 正文 1.5，标题 1.3 |
| 数字 | 等宽数字用于时长/计数（`font-variant-numeric: tabular-nums`） |

---

## 5. 布局与间距

- **基准网格**：4px。
- **常用间距**：8 / 12 / 16 / 20 / 24px。
- **页面边距**：16px。
- **圆角**：小 8px / 中 12px / 大 20px / 全圆 999px（胶囊）。
- **安全区**：顶部 `env(safe-area-inset-top)`，底部 `env(safe-area-inset-bottom)`。

### 主页面布局

```
Header   ─ 高度 56px + 安全区
Content  ─ flex:1，包含三栏标签 + 栏目内容
PlayerBar ─ 高度 64px + 安全区
```

## 7. 动效规范

| 动效 | 时长 | 缓动 |
| --- | --- | --- |
| 主题切换 | 250ms | ease |
| 抽屉滑入 | 280ms | cubic-bezier(0.22, 1, 0.36, 1) |
| 标签切换 | 200ms | ease |
| 按钮反馈 | 120ms | ease-out |
| 炫彩背景流动 | 18s | linear（循环） |

> 原则：动效服务于空间关系与反馈，避免过度装饰。

---

## 8. 交互规范

- **点击**：按钮有轻微缩放反馈（scale 0.96）。
- **滑动**：三栏支持左右滑动切换。
- **长按**：队列项长按进入排序/更多操作（预留）。
- **反馈**：关键操作（置顶、添加队列）用轻提示（toast）确认。
- **空态**：无数据时展示友好插画 + 引导文案。

---

## 9. 可访问性

- 语义化标签与 `aria-label`。
- 图标按钮提供文字说明。
- 支持系统字体缩放。
- 开关控件支持键盘操作（Web 端）。
